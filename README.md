# StudyLoop — Adaptive AI Academic Copilot

A full-stack student productivity prototype built around the loop: Plan → Study → Measure → Detect gaps → Replan → Repeat.

## Features
- Adaptive study planning and recovery replanning
- Focus sessions and progress tracking
- AI-powered study assistance, notes, quizzes and feedback
- Recovery dashboard with Study Reality Score
- PWA-friendly student workflow

## Local setup
This project uses pnpm workspaces. Configure `DATABASE_URL` and `OPENAI_API_KEY` before running the backend.
